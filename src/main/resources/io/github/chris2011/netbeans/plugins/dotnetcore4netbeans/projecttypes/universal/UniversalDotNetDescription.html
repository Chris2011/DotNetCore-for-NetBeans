.NET Project

Create a new .NET project using the official .NET CLI templates. This wizard allows you to select from all available project templates and configure your solution structure.

Features:

  • All Template Types: Access to all official .NET CLI templates including console apps, web APIs, Blazor apps, class libraries, test projects, and more
  • Categorized Templates: Templates are organized by category (Web Development, Desktop Development, Mobile Development, etc.)
  • Flexible Solution Options: Create empty solutions, solutions with projects, or add projects to existing solutions
  • Language Support: Full support for C#, F#, and VB.NET where available
  • Future-Proof: Automatically supports new templates as they become available in the .NET CLI

Wizard Steps:

  1. Template Selection: Browse and select from categorized .NET project templates
  2. Project Configuration: Configure project name, language, and template-specific options
  3. Solution Configuration: Choose how to organize your project within a solution

Solution Options:

  • Create new solution with project: Creates both solution and project together
  • Create empty solution only: Creates just the solution file for later project additions
  • Add project to existing solution: Adds the new project to an existing solution

This unified approach replaces individual project type wizards and provides a consistent experience for creating any type of .NET project.
